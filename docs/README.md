# UniCrypt GitHub Pages Edition

هذه نسخة HTML/CSS/JavaScript ثابتة تعمل على GitHub Pages بدون Python أو قاعدة بيانات أو اشتراك.

تدعم:

- واجهة UniCrypt العربية RTL.
- الوضع الداكن والفاتح.
- معمل AES-256-GCM داخل المتصفح عبر Web Crypto API.
- محادثة تجريبية محلية باستخدام localStorage.

هذه النسخة لا تدعم محادثة حقيقية بين أجهزة مختلفة أو WebSocket أو حفظًا دائمًا على الإنترنت. لا تستخدمها للبيانات السرية.
